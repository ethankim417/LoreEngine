# Screenshot Assets

This folder stores GitHub-facing visual assets for the LoreEngine repository README.

Current committed assets:

- `loreengine-dashboard.svg`: desktop dashboard preview.
- `loreengine-article-detail.svg`: article detail preview.
- `loreengine-market-pulse.svg`: market page preview.
- `loreengine-mobile.svg`: mobile dashboard preview.

These SVGs are lightweight README preview panels built from the current product content and visual language. They render directly on GitHub without needing external image hosting.

When browser screenshot capture is available, replace or supplement them with:

- `loreengine-dashboard.png`: desktop home dashboard above the fold.
- `loreengine-article-detail.png`: one article detail page with readable analysis.
- `loreengine-market-pulse.png`: market page showing grouped company context.
- `loreengine-mobile.png`: mobile dashboard view.

Capture notes:

- Use the real deployed URL when possible.
- Avoid browser chrome if the screenshot is for the README.
- Keep text readable at GitHub README width.
- Do not add placeholder images that imply features or data the app does not have.
- Keep SVG previews and real screenshots visually aligned with the live product.
